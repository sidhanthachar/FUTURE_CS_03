# FUTURE_CS_03

## API Security Risk Analysis Report

This project was completed as part of the Future Interns Cyber Security Internship program.

## Objective

The objective of this task was to analyze public API endpoints, identify common API security risks, assess authentication and data exposure practices, and provide remediation recommendations.

## Tools Used

* Postman
* Browser DevTools
* Public API Endpoints
* Canva / Documentation Tools

## Scope

* API endpoint inspection
* Response analysis
* Authentication review
* Data exposure analysis
* Risk classification
* Security recommendations

## Key Findings

* Publicly accessible endpoints
* Missing visible authentication controls
* Excessive data exposure risks
* Lack of visible rate limiting
* Public API accessibility concerns

## Repository Contents

* API security report
* Evidence screenshots
* Endpoint analysis
* Risk assessment documentation

## Ethical Notice

This project was conducted strictly for educational and cybersecurity awareness purposes using ethical and non-intrusive analysis methods only.
